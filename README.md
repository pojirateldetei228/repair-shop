# Ремонтная мастерская

Веб-приложение для приёма заявок на ремонт техники и учёта запчастей.

## Основные возможности

- **Клиент:** просмотр каталога услуг, регистрация и вход, создание заявки с фото (описание 10–500 символов, фото jpg или png до 5 МБ), личный кабинет с историей заявок и текущим статусом.
- **Мастер:** просмотр назначенных заявок, смена статуса, комментарий, стоимость работ, списание запчастей со склада.
- **Администратор:** назначение заявок мастерам, управление услугами, запчастями на складе и сотрудниками, статистика с графиками (по статусам, дням, типам устройств, загрузке мастеров и сумма дохода).

Статусы заявки: принята → в диагностике → в ремонте → готова к выдаче → выдана.

## Стек технологий

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, JavaScript (графики Chart.js, без интернета рисуются обычным JavaScript)
- **База данных:** SQLite (модуль sqlite3)

## Как запустить проект локально

1. Установите Python 3 (при установке отметьте галочку **Add python.exe to PATH**).
2. Скачайте проект и распакуйте архив.
3. Откройте папку с проектом в консоли (в адресной строке папки введите `cmd`) или в VS Code.
4. Установите Flask: `pip install -r requirements.txt`
5. В консоли выполните команду: `python app.py`
6. Перейдите в браузере по адресу: http://127.0.0.1:5000

При первом запуске автоматически создастся файл базы данных `shop.db` с тестовыми данными.

## Структура проекта

- `app.py` — серверная логика, маршруты, роли и работа с БД.
- `schema.sql` — структура базы данных (таблицы users, services, parts, requests, request_parts).
- `templates/` — HTML-страницы.
- `static/` — стили (`style.css`) и папка `uploads/` с фото заявок.
- `test_app.py` — простой автотест (`python test_app.py`; он создаёт и удаляет свою `shop.db`, поэтому запускайте его до работы с сайтом).
- `shop.db` — файл базы данных SQLite, создаётся при первом запуске.
